# Epic Island

![Epic Adventures Island](cover.jpg)

**Epic Island** (EPIC ADVENTURES — ISLAND) es un juego educativo 3D de EpicGroup Lab, para navegador y realidad virtual.
La isla está organizada en distritos, cada uno dedicado a una materia diferente.
En cada distrito hay salas de aprendizaje donde se trabajan los contenidos de esa materia.
Nuevos distritos y materias se irán sumando a la isla.

Jugar: https://davidegl.github.io/isla--pica/
